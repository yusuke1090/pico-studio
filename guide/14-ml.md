# 14. 機械学習モデルの導入

## この章でわかること

- マイコンで機械学習を動かすときの考え方（TinyML）
- センサーデータから「特徴量」を作る
- データを集めて、PC で学習する
- 学習した決定木を、ピコで動く C++ のコード（`model.h`）に変換して判定する
- もっと大きなモデルを使いたいときの選択肢

8・9章（MPU-6050 の配線と読み取り）と13章（データを PC に送る）が済んでいることが前提です。

## 全体の流れ

![マイコンで機械学習を動かす流れ](images/ml-flow.svg)

1. **集める**: ピコでセンサーのデータを取り、行動の名前（ラベル）を付けて保存する
2. **学習する**: PC で scikit-learn を使ってモデルを作る
3. **変換する**: 学習したモデルを、ピコで動くコードに変換する
4. **推論する**: ピコの上でモデルを動かして、その場で判定する

**学習は PC、推論（判定）だけをマイコン** で行うのが基本です。
ピコの RAM は約200KB しかないので、学習そのものはできませんが、小さなモデルで判定するだけなら十分に動きます。

### 言葉の説明

| 言葉 | 意味 |
| --- | --- |
| ラベル | データに付ける「正解の名前」。例: rest（休む）、walk（歩く）、eat（食べる） |
| 特徴量 | 生データの特徴をまとめた数値。例: 2秒間の平均、ばらつき |
| 窓 | データを区切る単位。この章では2秒 |
| 学習 | データとラベルの組から、判定のルールを作ること |
| 推論 | 作ったルールで、新しいデータのラベルを当てること |
| モデル | 学習で作った判定のルール |

## 生データではなく「特徴量」を使う

加速度を 25Hz で 2秒測ると、3軸 × 50回 = 150個の数値になります。
これをそのままモデルに入れるより、**特徴をよく表す少ない数値（特徴量）** にまとめた方が、小さく正確なモデルになります。

![生データから特徴量を作って判定するまで](images/windows-features.svg)

| 特徴量 | 何がわかるか |
| --- | --- |
| 各軸の平均 | 首の向き（頭を上げている・下げている） |
| 各軸の標準偏差 | 各方向の動きの大きさ |
| 加速度の大きさの標準偏差 | 全体の動きの激しさ（歩行は大きい、休息は小さい） |
| 加速度の大きさの変化量の平均 | 細かく速い動き（咀嚼・反芻） |

この例では、2秒ごとに次の **8個** の特徴量を作ります。
`mean_x, mean_y, mean_z, std_x, std_y, std_z, std_mag, diff_mag`

> **標準偏差** は「値がどれくらいばらついているか」です。じっとしていると小さく、激しく動くと大きくなります。

## ステップ1: データを集める（ピコ）

C++ にはファイルのしくみがないので、特徴量を **CSV の形で `printf`** して、PC で受け取ります。
`LABEL` を行動の名前にして書き込み、その行動をしている間データを取ります。

```cpp run
#include <cmath>
#include <cstdio>
#include "pico/stdlib.h"
#include "mpu6050.h"

const char* LABEL = "rest";           // ← 行動の名前。walk / eat / rest など、変えながら何回か書き込む
constexpr int WINDOWS = 30;           // 2秒 × 30回 = 1分間集める
constexpr int HZ = 25;
constexpr int N = HZ * 2;             // 1つの窓のサンプル数

Mpu6050 mpu(i2c0);
float xs[N], ys[N], zs[N];

// 2秒分を、決まった間隔で集める
void window() {
    absolute_time_t next = get_absolute_time();
    for (int i = 0; i < N; i++) {
        mpu.read_accel(xs[i], ys[i], zs[i]);
        next = delayed_by_ms(next, 1000 / HZ);
        sleep_until(next);
    }
}

float mean(const float* a) {
    float s = 0;
    for (int i = 0; i < N; i++) s += a[i];
    return s / N;
}

float stdev(const float* a, float m) {
    float s = 0;
    for (int i = 0; i < N; i++) s += (a[i] - m) * (a[i] - m);
    return sqrtf(s / N);
}

// 8個の特徴量を作る。判定のとき（ステップ3）も、必ずこれと同じ計算にする
void features(float fe[8]) {
    float mag[N];
    for (int i = 0; i < N; i++) mag[i] = sqrtf(xs[i] * xs[i] + ys[i] * ys[i] + zs[i] * zs[i]);
    float mx = mean(xs), my = mean(ys), mz = mean(zs), mm = mean(mag);
    float diff = 0;
    for (int i = 1; i < N; i++) diff += fabsf(mag[i] - mag[i - 1]);
    fe[0] = mx;  fe[1] = my;  fe[2] = mz;
    fe[3] = stdev(xs, mx);  fe[4] = stdev(ys, my);  fe[5] = stdev(zs, mz);
    fe[6] = stdev(mag, mm);
    fe[7] = diff / (N - 1);
}

int main() {
    stdio_init_all();
    mpu.begin(4, 5);
    sleep_ms(3000);                   // 書き込んでから、動きを始めるまでの準備の時間

    for (int w = 0; w < WINDOWS; w++) {
        window();
        float fe[8];
        features(fe);
        for (int i = 0; i < 8; i++) printf("%.4f,", fe[i]);
        printf("%s\n", LABEL);
    }
    printf("おわり\n");
    while (true) sleep_ms(1000);
}
```

2秒ごとに、出力欄に1行ずつ出ます。

```text
0.0123,-0.0201,0.9987,0.0031,0.0029,0.0035,0.0024,0.0021,rest
0.0119,-0.0198,0.9991,0.0028,0.0031,0.0033,0.0022,0.0019,rest
```

- `float mag[N];` は関数の中の配列ですが、50個（200バイト）と小さいので大丈夫です。大きな配列は関数の外に置きます（13章）
- `sqrtf`、`fabsf` は `float` 用の関数です（`f` のない `sqrt` は `double` 用で遅い）

### 練習のしかた（牛がいなくても試せる）

センサーを手に持って、自分で動きをまねしてデータを集めてみましょう。

| LABEL | やること |
| --- | --- |
| `rest` | センサーを机に置いて、動かさない |
| `walk` | センサーを持って、ゆっくり歩く（または手で上下に大きく揺らす） |
| `eat` | センサーを持った手を、小さく速く左右に動かす |

1. `LABEL = "rest"` にして書き込み、Serial Monitor で出力を見始める。1分間、動かさずに待つ
2. `LABEL = "walk"` に書き換えて、もう一度書き込む。1分間、歩く動きをする
3. `LABEL = "eat"` に書き換えて、もう一度書き込む。1分間、小さく速い動きをする
4. Serial Monitor に出た数字の行を選んでコピーし、テキストエディタの `features.csv` に貼り付けていく（`おわり` などの行は除く）

> **実際の牛のデータでは**: 首輪にセンサーを付けて記録しながら、同じ時間の動画を撮っておき、あとで動画を見て「この2秒は採食」とラベルを付けるのが一般的です。
> 1つの行動につき、少なくとも数十〜数百個の窓を集めると安定します。

> コピーの代わりに、13章の `pc_logger.py` のように PC 側のプログラムで受け取って保存することもできます。その場合は、`line.count(",") == 8` の行だけを保存するように書き換えます。

## ステップ2: PC で学習する

ここからは **PC で** 動かします。scikit-learn が必要です。

```bash
sudo apt install python3-sklearn
```

決定木（Decision Tree）は、「もし std_mag が 0.05 以下なら…」という **if 文の組み合わせ** で判定するモデルです。
計算が軽く、if 文にそのまま変換できるので、マイコンにとても向いています。

![決定木のイメージ](images/decision-tree.svg)

```python
# train.py  ― 使い方: python3 train.py
import csv
from sklearn.tree import DecisionTreeClassifier
from sklearn.model_selection import train_test_split
from sklearn.metrics import classification_report

NAMES = ["mean_x", "mean_y", "mean_z", "std_x", "std_y", "std_z", "std_mag", "diff_mag"]

X, y = [], []
with open("features.csv") as f:
    for row in csv.reader(f):
        if len(row) == 9:
            X.append([float(v) for v in row[:8]])
            y.append(row[8])

X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.3, random_state=0, stratify=y)

clf = DecisionTreeClassifier(max_depth=4, random_state=0)   # 深さを制限して小さく保つ
clf.fit(X_train, y_train)
print(classification_report(y_test, clf.predict(X_test)))

def export(clf, names):
    """決定木を MicroPython の if 文に変換する"""
    t = clf.tree_
    lines = ["# train.py で自動生成した決定木", "def predict(f):"]

    def walk(node, depth):
        pad = "    " * depth
        if t.feature[node] >= 0:                      # 分岐のノード
            i = t.feature[node]
            lines.append(f"{pad}if f[{i}] <= {t.threshold[node]:.6f}:  # {names[i]}")
            walk(t.children_left[node], depth + 1)
            lines.append(f"{pad}else:")
            walk(t.children_right[node], depth + 1)
        else:                                         # 葉（判定結果）
            label = clf.classes_[t.value[node][0].argmax()]
            lines.append(f"{pad}return {str(label)!r}")

    walk(0, 1)
    return "\n".join(lines) + "\n"

with open("model.py", "w") as f:
    f.write(export(clf, NAMES))
print("model.py を作りました")

def export_cpp(clf, names):
    """決定木を C++ の if 文に変換する"""
    t = clf.tree_
    lines = ["// train.py で自動生成した決定木", "#pragma once", "",
             "inline const char* predict(const float* f) {"]

    def walk(node, depth):
        pad = "    " * depth
        if t.feature[node] >= 0:
            i = t.feature[node]
            lines.append(f"{pad}if (f[{i}] <= {t.threshold[node]:.6f}f) {{  // {names[i]}")
            walk(t.children_left[node], depth + 1)
            lines.append(f"{pad}}} else {{")
            walk(t.children_right[node], depth + 1)
            lines.append(f"{pad}}}")
        else:
            label = clf.classes_[t.value[node][0].argmax()]
            lines.append(f'{pad}return "{label}";')

    walk(0, 1)
    lines.append("}")
    return "\n".join(lines) + "\n"

with open("model.h", "w") as f:
    f.write(export_cpp(clf, NAMES))
print("model.h を作りました（C++ 用）")
```

> コードの中の関数名や引数名（`train_test_split`、`stratify`、`max_depth` など）をクリックすると、意味が出ます（0章）。

### 手順

1. 「コピー」ボタンで上のコードをコピーし、`features.csv` と同じフォルダに `train.py` として保存する
2. ターミナルでそのフォルダに移動して、`python3 train.py` を打つ
3. 成績表が表示され、同じフォルダに `model.h`（C++ 用）と `model.py`（MicroPython 用。付録E で試すとき）ができる

### 成績表の読み方

```text
              precision    recall  f1-score   support

         eat       0.89      0.89      0.89         9
        rest       1.00      1.00      1.00         9
        walk       0.89      0.89      0.89         9

    accuracy                           0.93        27
```

| 項目 | 意味 |
| --- | --- |
| precision | 「eat」と判定したもののうち、本当に eat だった割合 |
| recall | 本当の eat のうち、ちゃんと eat と判定できた割合 |
| f1-score | precision と recall のバランス。1.00 が満点 |
| support | テストに使ったデータの数 |
| accuracy | 全体の正解率 |

- 学習に使っていないデータ（全体の30%）で成績を測っています
- 正解率が低いときは、データを増やす・特徴量を増やす・`max_depth` を変える

できた `model.py` は、たとえばこんな中身になります。

```python
def predict(f):
    if f[6] <= 0.031200:  # std_mag
        return 'rest'
    else:
        if f[7] <= 0.084500:  # diff_mag
            return 'eat'
        else:
            return 'walk'
```

上の図の決定木を、そのまま if 文にしたものです。`f[6]` は8個の特徴量のうち7番目（std_mag）です（0から数えます）。

## ステップ3: ピコで判定する

`model.h` は次のような形です（中身は学習したデータで変わります）。

```text
// train.py で自動生成した決定木
#pragma once

inline const char* predict(const float* f) {
    if (f[6] <= 0.041200f) {  // std_mag
        return "rest";
    } else {
        if (f[7] <= 0.183000f) {  // diff_mag
            return "walk";
        } else {
            return "eat";
        }
    }
}
```

1. PC にできた `model.h` を、VS Code のプロジェクトのフォルダにコピーする（例: `cp model.h ~/apps/collar/`）
2. `mpu6050.h` もコピーしておく（9章）。`CMakeLists.txt` には `hardware_i2c` を足す
3. 次のプログラムを `.cpp` に貼り付けて、Compile → Run

```cpp run
#include <cmath>
#include <cstdio>
#include "pico/stdlib.h"
#include "mpu6050.h"
#include "model.h"                    // train.py で作った model.h

constexpr int HZ = 25;
constexpr int N = HZ * 2;

Mpu6050 mpu(i2c0);
float xs[N], ys[N], zs[N];

void window() {
    absolute_time_t next = get_absolute_time();
    for (int i = 0; i < N; i++) {
        mpu.read_accel(xs[i], ys[i], zs[i]);
        next = delayed_by_ms(next, 1000 / HZ);
        sleep_until(next);
    }
}

float mean(const float* a) {
    float s = 0;
    for (int i = 0; i < N; i++) s += a[i];
    return s / N;
}

float stdev(const float* a, float m) {
    float s = 0;
    for (int i = 0; i < N; i++) s += (a[i] - m) * (a[i] - m);
    return sqrtf(s / N);
}

// ステップ1と同じ計算
void features(float fe[8]) {
    float mag[N];
    for (int i = 0; i < N; i++) mag[i] = sqrtf(xs[i] * xs[i] + ys[i] * ys[i] + zs[i] * zs[i]);
    float mx = mean(xs), my = mean(ys), mz = mean(zs), mm = mean(mag);
    float diff = 0;
    for (int i = 1; i < N; i++) diff += fabsf(mag[i] - mag[i - 1]);
    fe[0] = mx;  fe[1] = my;  fe[2] = mz;
    fe[3] = stdev(xs, mx);  fe[4] = stdev(ys, my);  fe[5] = stdev(zs, mz);
    fe[6] = stdev(mag, mm);
    fe[7] = diff / (N - 1);
}

int main() {
    stdio_init_all();
    mpu.begin(4, 5);

    while (true) {
        window();
        float fe[8];
        features(fe);
        uint64_t t0 = time_us_64();
        const char* label = predict(fe);
        unsigned us = static_cast<unsigned>(time_us_64() - t0);
        printf("判定: %s  （判定にかかった時間 %u us）\n", label, us);
    }
}
```

2秒ごとに、次のように判定結果が出ます（時間は例です）。センサーを動かして、判定が変わるか確かめましょう。

```text
判定: rest  （判定にかかった時間 2 us）
判定: walk  （判定にかかった時間 2 us）
```

> 特徴量を作る `features()` は、**集めたときと必ず同じ計算**にしてください。
> 少しでも違うと、PC で測った正解率が出ません。

> `fatal error: model.h: No such file or directory` と出たら、`model.h` がプロジェクトのフォルダ（`.cpp` と同じ場所）にありません。

決定木の判定は数マイクロ秒で終わります。特徴量の計算を含めても、2秒のうちのごくわずかです。

## もっと大きなモデルを使いたいとき

| 方法 | 向いているもの | 言語 |
| --- | --- | --- |
| 決定木を if 文に変換（この章） | 少ない特徴量でのシンプルな分類 | C++（MicroPython も） |
| [emlearn](https://github.com/emlearn/emlearn) | ランダムフォレスト・小さなニューラルネットなど scikit-learn のモデル | C（[MicroPython 版](https://github.com/emlearn/emlearn-micropython)もある） |
| [LiteRT for Microcontrollers](https://ai.google.dev/edge/litert/microcontrollers/overview) / [pico-tflmicro](https://github.com/raspberrypi/pico-tflmicro) | TensorFlow / Keras で作ったニューラルネット（音声や生データを直接使う） | C++ |
| [Edge Impulse](https://edgeimpulse.com/) | データ集め・ラベル付け・学習・書き出しをブラウザでまとめてやりたい | C++ に書き出し |

**選び方の目安**

- まずは決定木で試す。行動がある程度分けられるかを確認するのに十分
- 精度が足りなければ、ランダムフォレスト（emlearn）
- 生の波形から直接学習したい、音も使いたいなら、ニューラルネット（LiteRT / Edge Impulse、C++）

### モデルを小さくするコツ

- 決定木は `max_depth` を 4〜8 くらいに抑える
- ニューラルネットは **int8 量子化** すると、サイズが約1/4になり速くなる
- 特徴量を減らす（効いていないものは `clf.feature_importances_` でわかる）

## まとめ

- 学習は PC、判定だけをピコで行う
- 生データを2秒ごとの特徴量にまとめてから、モデルに入れる
- 決定木は if 文に変換でき、`model.h` を `#include` すれば C++ でそのまま動く
- 大きなモデルは emlearn・LiteRT・Edge Impulse（C/C++）を使う
